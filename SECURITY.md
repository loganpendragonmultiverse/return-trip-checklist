# Security

Please report vulnerabilities through this repository’s private vulnerability reporting feature where available. Do not attach personal photos, receipts or unredacted backups to public issues.

Return Trip Checklist has no server, accounts, telemetry or runtime network requests. Browser storage and JSON backups are not encrypted. The app validates bounded text and attachment structures but does not scan PDFs for malware or guarantee file provenance. Open trusted documents only. It refuses SVG/HTML attachment types. Keep independent backups and use one browser tab at a time.

Only the current published version is considered for fixes; ongoing maintenance is discretionary.
